# Okay, some R code

```{r linear-model}
fit = lm(dist ~ speed, data = cars)
b = coef(fit)  # coefficients
summary(fit)
```

The code will be highlighted in all output formats.


# A little bit math

Our regression equation is $Y=`r b[1]`+`r b[2]`x$, and the model is:

$$ Y = \beta_0 + \beta_1 x + \epsilon$$
