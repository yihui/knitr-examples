You can also tell knitr not to touch your source code using the chunk option tidy=FALSE, so that you can format the source code in any way you want:

<<tidy-test, tidy=FALSE>>=
1 + 1 +
  1+1+
  1
f = function() {
  paste('I want to break the line',
        'here!')
}
@
